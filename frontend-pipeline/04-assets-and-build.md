# 04 – Assetai ir build

1. Pirma patikrink, ar identiškas assetas jau yra `public/assets/`.
2. Naują Figma eksportą saugok semantiniu vardu ir tik lokaliai.
3. Patikrink `currentSrc`, natural dydį, rendered dydį ir Figma frame dydį.
4. Paleisk `npm run build` po source pakeitimų.

Nenaudok screenshot kaip production asseto ir nekompensuok netinkamo asseto CSS crop'u.
