# 06 – Užbaigimas

Užduotis baigta tik kai source kodas, assetai, build ir Chrome DevTools įrodymai atitinka užduotį.

Galutiniame atsakyme nurodyk:

1. Kas pakeista.
2. Naudotą Figma node ir komponentų/layerių struktūrą.
3. `npm run build` rezultatą.
4. Atliktas Chrome DevTools patikras ir jų rezultatą.
5. Ko nepatikrinai bei likusią riziką.

Nesakyk „padaryta“, jei nėra visų prašytų layerių, elgesių ar browser įrodymų.
